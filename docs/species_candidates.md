# FieldSnap NZ — Candidate Species List (20 classes)

This is a **candidate list** of 20 species (10 birds, 10 plants) commonly encountered in Tāmaki Makaurau /
Auckland, compiled to scope a small offline image-classification app. It is **not** a final class list: the
class list is frozen only after licence filtering, de-duplication and sample inspection are complete. Compiled
**11 September 2026**, counts re-measured the same day. Photo-availability counts were measured live against
the iNaturalist API (place = New Zealand, research grade, photos only) and are indicative, not fixed.

## Licence policy for this round (decided by the project owner, 2026-09-11)

- **Accepted: `CC0` and `CC BY` only.** CC BY still requires attribution, a licence link and a note of any
  changes, so every downloaded image must be recorded in a per-image manifest.
- **`CC BY-SA` is a fallback only** if a class cannot reach the sample target; it is not mixed in by default,
  because ShareAlike adds obligations to adaptations.
- **`CC BY-NC` is excluded this round.** The NC restriction is not dismissed as harmless just because this is
  coursework; excluding it now avoids constraints later.
- The count columns below therefore show **CC0+CC BY** first, with the CC BY-SA figure in brackets.
- **Licence is per photo, not per observation.** iNaturalist licenses observations and their photos
  separately; the observation licence must never be used in place of each photo's `license_code`.
- **`verified-open` in the table means only that a licence-compliant example file was inspected for that
  class** — it is not a class-level clearance. DOC and NZPCN material is **not** cleared for download, and
  citing a species description is not the same as being allowed to copy site images.
- Nothing has been downloaded yet; per-image licence, author, source URL and licence URL belong in the 1A
  manifest, not in this table.

## How to fetch images

All commands below were run successfully on 11 Sep 2026 except where marked "unverified"; nothing was downloaded.

### 1. iNaturalist observations API (preferred: queryable by scientific name)

**Critical correction: New Zealand's iNaturalist `place_id` is `6803`, not `7143`.**
`7143` is **Eswatini** (verified directly: `https://api.inaturalist.org/v1/places/7143`).
New Zealand verified at `https://api.inaturalist.org/v1/places/6803`. Do not trust the widely-copied `7143`.

Endpoint pattern (research grade, photos only, CC licences only, New Zealand):

```bash
curl -s "https://api.inaturalist.org/v1/observations?taxon_name=Prosthemadera%20novaeseelandiae&place_id=6803&photos=true&photo_license=cc0,cc-by&quality_grade=research&per_page=200&page=1" \
  | python3 -c "import sys,json; d=json.load(sys.stdin); print(d['total_results']); [print(o['id'], o['taxon']['name'], [p['url'] for p in o['photos']]) for o in d['results'][:5]]"
```

Reference command to count usable photos per candidate class (swap the taxon name):

```bash
for t in "Prosthemadera novaeseelandiae" "Hemiphaga novaeseelandiae" "Metrosideros excelsa"; do
  curl -s "https://api.inaturalist.org/v1/observations?taxon_name=$(python3 -c "import urllib.parse,sys;print(urllib.parse.quote(sys.argv[1]))" "$t")&place_id=6803&photos=true&photo_license=cc0,cc-by&quality_grade=research&per_page=0" \
    | python3 -c "import sys,json;print('$t', json.load(sys.stdin)['total_results'])"
done
```

Notes:
- `photo_license=cc0,cc-by` is the accepted set for this project. Add `cc-by-sa` **only** if a class cannot
  reach its sample target, and record that decision when it happens. `cc-by-nc` is excluded this round.
- iNaturalist returns a `license_code` field **per photo**. Use it for the manifest; do not copy the
  observation's licence onto the photos.
- Photo URLs come back as `square` thumbnails; swap the size token for a larger render, e.g.
  `url.replace("square", "large")` (or `"original"`). Measured 2026-09-11: `original` for research-grade NZ
  kererū records is typically 0.2–4.2 MP (median 2.8 MP) at a few hundred KB to ~2 MB.
- To be robust to taxonomy changes, resolve a stable `taxon_id` first and filter with `taxon_id=` instead of
  `taxon_name=`: `https://api.inaturalist.org/v1/taxa?q=Cyathea%20dealbata`. For silver fern, remember that
  `Cyathea dealbata`, `Alsophila tricolor` and `Alsophila dealbata` must all resolve to one internal class.
- If you cannot confirm the place_id, find it yourself:
  `curl -s "https://api.inaturalist.org/v1/places/autocomplete?q=New%20Zealand"`
- iNaturalist asks API users to be gentle — roughly one request per second, with caching, a descriptive
  User-Agent and retry/backoff. The API is not an unlimited bulk-download channel.

### 2. Wikimedia Commons API

Search by scientific name and pull the licence metadata in the same call (verified working):

```bash
curl -s -H "User-Agent: FieldSnapNZ/0.1 (the course student project; contact you@example.com)" \
  "https://commons.wikimedia.org/w/api.php?action=query&format=json&generator=search&gsrsearch=filetype:bitmap%20Cyathea%20dealbata&gsrnamespace=6&gsrlimit=20&prop=imageinfo&iiprop=url%7Cextmetadata" \
  | python3 -c "
import sys,json,re
d=json.load(sys.stdin)
for p in (d.get('query',{}).get('pages',{}) or {}).values():
    ii=p.get('imageinfo')
    if not ii: continue
    em=ii[0].get('extmetadata',{})
    g=lambda k: re.sub('<[^>]+>','',str(em.get(k,{}).get('value','')))[:90].replace('\n',' ')
    print(p['title'], '|', g('LicenseShortName'), '|attr=', g('AttributionRequired'), '|', g('Artist'))
    print('   ', ii[0]['url'])
"
```

- Read the licence from `extmetadata.LicenseShortName`; read `AttributionRequired` and `Artist` for the credit line.
- A `User-Agent` header with contact details is required by Wikimedia policy; requests without one may be blocked.
- To enumerate a curated category instead of search, use `list=categorymembers` with
  `cmtitle=Category:Metrosideros excelsa` and `cmtype=file`.
- Licence filtering by machine (`haswbstatement:P275=...`) is possible in principle but was **not verified** here —
  filter on `LicenseShortName` in your own code instead.

### 3. Other sources

- **NZ Garden Bird Survey** identification pages host some openly licensed bird photos (one CC0 silvereye image
  was observed at `https://gardenbirdsurvey.nz/identification/`) — per-image licence is **unknown** unless stated,
  so check each one.
- **NZ Plant Conservation Network** (`https://www.nzpcn.org.nz/`) is recommended by Auckland Council for plant images, but its per-image licence was **not verified** — treat as **unknown** until checked.
- **DOC** (`https://www.doc.govt.nz/`) was **not verified** for open licensing; do not assume DOC images are reusable — treat as **unknown** unless a specific CC statement is present on the page.

### 4. Non-negotiable provenance requirement

For **every** downloaded image, record in a manifest (CSV/JSON, one row per file):

`species | common_name | file_path | source (inat|commons|other) | source_page_url | direct_file_url | licence_id
| licence_url | author/creator | attribution_string | date_retrieved`

- **CC0 / Public domain**: no attribution legally required, but record the source anyway.
- **CC BY / CC BY-SA**: attribution is **required** — credit the author, the licence name and link the licence.
- **CC BY-NC / CC BY-NC-SA**: attribution is **required** *and* commercial use is forbidden.
- **CC BY-SA / CC BY-NC-SA**: derivative works (including a trained model, arguably) may need to be shared under
  the same licence — get this reviewed before training.
- Never fabricate or infer a licence. If it is not visible in the file's metadata or source page, record `unknown`.

## Risks and open questions

1. **iNaturalist place_id trap.** The `7143` value circulating online is Eswatini, not New Zealand (verified
   above). Any pipeline built on it would silently train on the wrong country. Use `6803`, and re-verify it.
2. **Class imbalance — but it does not have to reach the training set.** Under the accepted CC0/CC BY filter the
   available counts span 234 (common myna) to 3,633 (kererū), a ~15× spread, down from ~18,000 when NC was
   included. The plan is a **per-class sampling cap**: take the same number of images from every class (50–100
   for the 1A/1B feasibility check) instead of mirroring platform availability. Do not add class weights or
   resampling until the new-policy numbers show it is actually needed, and re-measure counts at build time
   because they change. Note the API reports *observations*, not unique photos.
3. **Look-alike pairs that will confuse a 20-class model.**
   - *Song thrush vs blackbird* — the hardest pair, but reviewed and **kept**: NZ Birds Online documents usable
     separation (speckled pale breast vs all-black adult male with yellow bill); only females/juveniles
     genuinely overlap. Sample sexes, ages and angles, and judge from validation-set confusion rather than
     dropping a class on impression.
   - *Tūī vs korimako* — both dark honeyeaters with similar posture.
   - *House sparrow vs dunnock / chaffinch / greenfinch* — small brown seed-eaters; only house sparrow is
     included here, but the model may still fire on the others in the field.
   - *Silver fern vs other ferns*; *wild ginger vs other ginger/Zingiber ornamentals*;
     *woolly nightshade vs other Solanum*; *moth plant flowers vs native climbers*.
   - Recommendation: keep a deliberate "unknown / not in list" rejection class, since users will photograph
     species outside the 20.
4. **Thinnest classes under the accepted licence set.** The smallest CC0/CC BY pools are **common myna (234)**,
   **moth plant (513)**, **woolly nightshade (562)** and **wild ginger (591)**; the largest is **kererū (3,633)**.
   All are comfortably above a 50–100 per-class target, so no class needs dropping for scarcity — but a class at
   ~234 observations may still yield fewer *distinct* images after de-duplication (multiple photos can come from
   one observation), so the fetch step must report the deduplicated per-class count.
5. **Taxonomy drift is a real engineering risk.** The silver fern is `Cyathea dealbata` on iNaturalist but its
   Commons files sit under `Alsophila tricolor`. `Hebe stricta` is now `Veronica stricta`. `Kunzea ericoides` and
   `Kunzea robusta` overlap in iNaturalist results. Prefer stable `taxon_id`/Commons category lookups over
   free-text names, and store both the name used and the ID.
6. **Plant/bird mix — easier or harder?** Likely **easier on average but unevenly**: plants and birds have very
   different image statistics (texture/leaf close-ups vs. whole-animal shots on varied backgrounds), so the
   coarse two-group split should be learned quickly. The difficulty is *within* groups: bird classes are
   background-dominated and pose-variable, while plant classes are dominated by flower close-ups, so the model
   may learn season/colour rather than species. A 20-class mixed model is a reasonable scope; the risk is not the
   mix but the two confusable pairs above.
7. **Domain shift within a class.** Several Commons results are herbarium specimens, museum skins or illustrations
   rather than field photos (e.g. the *Phormium tenax* MHNT sheet and the *Zosterops lateralis* Naturalis skin).
   These will hurt an app that only ever sees field photos — filter them out manually.
8. **Open questions to resolve before building.**
   - ~~Is NonCommercial (CC BY-NC) acceptable?~~ **Resolved 2026-09-11: excluded this round.** Only CC0 and
     CC BY are accepted; CC BY-SA is a fallback if a class cannot reach its sample target.
   - Does a trained model count as a derivative work for ShareAlike purposes? Still open, and the reason CC BY-SA
     is not the default. Needs a licence review before any SA image is used for training.
   - Which internal class name owns each taxon synonym set (e.g. silver fern)? Needs a fixed mapping in 1A.
   - What is the minimum viable images-per-class threshold (~200? ~500?) and does every class clear it after
     deduplication and NSFW/illustration filtering?
   - Should the class list be trimmed to ~12 to raise per-class data quality instead of holding 20?
